# Cuarteto Ludos — sitio web

Sitio estático (HTML + CSS + JS, sin dependencias) del Cuarteto Ludos.

- `index.html`: todo el sitio. Las secciones Home, Experiencias, Repertorio, Videos y Contacto se muestran según el `#` de la dirección (por ejemplo `#contacto`).
- `img/`: fotos y logo, extraídos de los bocetos de diseño.
- El formulario de contacto envía los mensajes a cuartetoludos@gmail.com mediante [Web3Forms](https://web3forms.com) (cuenta de cuartetoludos@gmail.com). La llave `W3F_KEY` en `index.html` es pública por diseño.

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
